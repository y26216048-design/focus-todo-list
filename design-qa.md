# Независимый аудит VELIO — 11 ноября 2026

Проверена исходная версия `b2c14ef` и исправленная статическая сборка. Аудит выполнен с помощью Codex, Playwright и axe-core: выводы основаны на чтении кода, воспроизведении ошибок и проверке результата в браузерах. Это отчёт о проверенном объёме, а не гарантия отсутствия любых дефектов.

Пять регрессионных тестов запущены и на исходной версии: защита повреждённых данных, смена дня, клавиатурный фокус, синхронизация темы и устаревшая вкладка. Все пять выявили соответствующие ошибки. Исходная арифметика прогресса уже была верна; аудит усиливает её проверку и убирает неточные названия/описания.

## Проверяемые сценарии

`npm test` выполняет четыре файла:

- `tests/browser.py`: создание с датой/временем, выполнение, возврат в активные, удаление/отмена, перезагрузка, три раздела, обе темы, пустые списки, календарь и Escape, безопасный вывод HTML-подобного текста, прокрутка и сетевые/JavaScript-ошибки.
- `tests/layout.py`: заполнение окна, центровка счётчиков, карточки статистики, календарь, переходы между разделами и reduced motion. Прогресс при возврате в «Сегодня» сразу равен итоговому значению.
- `tests/audit.py`: 12 изолированных регрессионных сценариев, включая очередь Web Locks, перезагрузку до выполнения асинхронной записи, повреждение/запрет/переполнение localStorage, миграцию, быстрые нажатия, предел названия, неверный ввод, срок отмены (в том числе после добавления другой задачи и открытия календаря), полночь и часовые пояса UTC+14/Лос-Анджелес.
- `tests/accessibility.py`: 36 состояний на движок — три раздела, календарь и отмена удаления внутри/вне диалога, в двух темах на 320, 768 и 1440 px. Проверяются правила axe с тегами WCAG 2 A/AA и 2.1 AA.

Проценты проверяются в том же JavaScript-вызове, который нажимает checkbox: текст всех индикаторов и CSS-значение обоих колец должны совпасть. Проверяются 0%, 33%, 50%, 67%, 100%, удаление, восстановление и перезагрузка. Формула: округлённая доля выполненных среди **всех** неудалённых задач; пустой список даёт 0%.

Команды: `npm ci`, `npm run format:check`, `npm run build`, затем `npm test` для каждого `BROWSER=chromium`, `firefox`, `webkit`. Статический сервер обслуживает `dist/`; CI запускает ту же матрицу. Результат конкретного коммита доступен в [GitHub Actions](https://github.com/y26216048-design/focus-todo-list/actions/workflows/check.yml). Локальная матрица завершилась успешно. `npm audit` не обнаружил известных уязвимостей. Запуск Vite по README и смена часового пояса в открытой вкладке дополнительно проверены в Chromium через CDP; явно выбранная дата сохранилась.

Скриншоты сценариев сохраняются в `test-results/<движок>/`; актуальные иллюстрации README — `docs/desktop.png` и `docs/mobile.png`.

В облачном окружении WebKit потребовал библиотек Debian, распакованных в рабочую папку и подключённых к пользовательскому браузерному пакету. Системного доступа root не было. Предварительная проверка системного кеша библиотек отключена только для этого локального запуска; сам браузер, его рендеринг и проверки работают. В CI библиотеки устанавливаются стандартной командой Playwright `install --with-deps`.

## Публикация и кеш

GitHub Pages обслуживает `main`, папку `/`. `npm run build` вычисляет хэши CSS/JavaScript и записывает их в корневой `index.html`; этот файл включается в коммит. Для проверки опубликованного сайта используется `BASE_URL=https://y26216048-design.github.io/focus-todo-list/ npm test`.

После push дополнительно проверяются успешная публикация нужного коммита, совпадение байтов ресурсов и их хэшей с локальной сборкой, а также перезагрузка браузерного контекста, который до публикации открывал предыдущую версию. Публичные прогоны используют изолированные контексты и не обращаются к данным реального пользователя. Результат проверки публикации сообщается отдельно после push.

## Границы проверки

- Исходный текст задания The Digital и исходные дизайн-макеты не предоставлены. Проверены требования из запроса, репозиторий и документация; точное соответствие непредоставленному заданию или пиксельное совпадение с макетами подтвердить нельзя.
- Физические Android/iOS-устройства, Safari на macOS, скринридеры NVDA/VoiceOver и нативные системные окна выбора даты не проверены. WebKit на Linux не равнозначен Safari на устройстве.
- Не проверены все мировые часовые пояса и все переходы DST. Проверены полночь и конкретные зоны; время хранится как локальная подпись, без преобразования в UTC и без уведомлений.
- Очистка данных, аварийное завершение браузера/устройства и отказ диска могут привести к потере локальных данных. Облачной копии нет. Защита обычной перезагрузки проверена; атомарность нескольких аварийно закрывающихся вкладок не гарантируется.
- axe не доказывает полное соответствие WCAG. Проверки безопасности ограничены обработкой пользовательского текста, хранилища, отсутствием внешних runtime-зависимостей и `npm audit`; это не формальный penetration test.
